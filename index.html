【数学】展開・因数分解の公式

展開: (x + a)(x + b)
= x² + (a + b)x + ab
例: (x - 7)(x + 3) = x² - 4x - 21
因数分解のコツ
「かけて端の数、足して真ん中の数」になる2つの数字を探す。

【英語】重要文法ルール

同格の比較 (as ... as)
as + 形容詞 + as = 「〜と同じくらい…」
例: as small as this (これと同じくらい小さい)
